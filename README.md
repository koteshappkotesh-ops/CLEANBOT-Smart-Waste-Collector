
# CLEANBOT – Smart Waste Collection and Segregation Vehicle

An ESP32-CAM-based smart waste collection and segregation vehicle featuring wireless control, camera monitoring, AI-based waste classification, and a robotic arm.

## Project Overview

CLEANBOT is a smart robotic vehicle designed to support waste collection and segregation using embedded systems, robotics, and AI-based classification.

The system combines a mobile robotic platform with a camera and robotic arm to assist in identifying, collecting, and handling waste.

## Objectives

- Develop a smart robotic waste collection vehicle.
- Implement wireless vehicle control.
- Integrate camera-based monitoring.
- Explore AI-based waste classification.
- Design a robotic arm for waste handling.
- Combine embedded systems and robotics in a practical application.

## Key Features

- Wireless vehicle control
- ESP32-CAM camera integration
- AI-based waste classification using Edge Impulse
- Robotic arm for waste handling
- Motor control using L298N
- Servo control using PCA9685

## Hardware Components

| Component | Purpose |
|---|---|
| ESP32-CAM | Main camera and embedded controller |
| L298N | DC motor driver |
| PCA9685 | Servo motor controller |
| DC Motors | Vehicle movement |
| Servo Motors | Robotic arm movement |

## Software and Technologies

- Arduino IDE
- ESP32
- Edge Impulse
- Embedded C/C++
- Wireless communication
- Robotics and motor control

## Working Principle

1. The vehicle is controlled wirelessly.
2. The ESP32-CAM provides camera-based monitoring.
3. AI-based classification is used to identify waste.
4. The robotic arm assists in handling waste.
5. The vehicle platform supports movement and collection operations.
